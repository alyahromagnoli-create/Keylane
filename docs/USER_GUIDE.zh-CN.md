# Keylane｜键径 1.0.1

一款离线的 Windows 键盘与 Excel 操作学习软件。

## 启动

双击同目录的 `Keylane_v1.0.1.exe`。无需安装 Python、Excel 或 AI API。首次解包需要几秒。


## 五个页面

- 首页：真实的练习次数、正确率、技能进度和按键反应时间。首次使用为空。
- 快捷键训练：Windows 常用 20 项、Excel 常用 20 项。选题后点击“开始接收按键”，直接按组合键；答对后可进入下一题。系统保留的 Win 系列及 Alt+Tab 使用虚拟键盘。虚拟键盘先点击 Ctrl/Alt/Shift/Win，再点击普通键，最后点击提交。Ctrl+Space 如被输入法拦截，也可虚拟练习。
- Excel 函数：13 种函数的讲解、模拟表格、公式输入、结果校验。SUM、AVERAGE、MAX、MIN、COUNT、COUNTA、IF、COUNTIF、SUMIF、VLOOKUP、ROUND、LEFT、RIGHT。可修改数据，公式正确时结果写入 F8；双击单元格可编辑。看过提示后仍需自行输入公式。
- 实战挑战：选择 A1:E5、按成绩降序排序、计算总分与平均分、判断及格、统计及格人数，六步按顺序验证。支持不限时、3 分钟、5 分钟。切换页面或离开应用暂停计时。按钮选区和鼠标选区均支持；选区阶段使用 Ctrl+A 才会增加快捷键计数。公式阶段的 Ctrl+A 保持文本全选用途。
- 我的成长：53 项技能地图、历史错题、双击复习、最近 14 个学习日、记录备份/恢复与 CSV 导出。

## 怎样判定掌握

至少一次正确练习计入学习进度。至少 3 次独立正确、且独立正确次数占全部作答 80% 以上，标为“熟练”。虚拟键盘和提示后的练习会被标记，不计入独立熟练；答错后展示答案，本题后续属于提示练习。下一次重新选题可独立作答。

首页按键反应时间只统计真实按键、无提示的正确作答。累计正确率为正确记录 / 全部记录，含各训练模块。挑战页单独显示该轮步骤正确率。历史错题保留历史，不因后续答对而删除。

公式既要使用指定函数，也要在原表和两组变化数据中得出正确结果，所以直接输入数值或把答案写死通常无法通过。该方法不是完整的符号等价证明；首版覆盖内置课程的常见解法。

## 本地数据


恢复会先校验数据库格式与完整性，再将现有记录备份为 data\before-restore.db，然后替换。请定期使用“备份学习记录”保存另一个副本。CSV 的公式作答列会增加文本前缀，以便 Excel 打开时保持为文字。

## 模拟范围

本软件是训练沙盒，不是 Excel 替代品。快捷键只在本窗口接收；场景预览不会真的锁屏、删除文件、打印或保存外部文档。只有已列出的少量表格操作有可视化状态变化，其余快捷键提供场景反馈。

公式支持 A1 引用、$ 绝对引用、区域、英文函数名、英文双引号文本、逗号或分号分隔、基本算术和比较、有限嵌套。仅支持本软件 13 种函数；无跨表/跨文件引用、宏、数组公式、Excel 导入导出或完整 Excel 类型转换。建议按课程给定的标准写法练习。VLOOKUP 近似匹配要求首列升序；未排序时明确报错。引用上限 A1:CV1000，单次区域最多 2000 格。

仅在本机 Windows 11 x64 验证；未在第二台实体电脑或 Windows 10 实机验证。程序未做代码签名。

## 源码与构建

源码 ZIP 内有 Python 源码、测试、图标原始 SVG 和构建脚本。建立 D 盘 Python 虚拟环境，安装 requirements.txt，再运行 build.ps1 -Python <Python完整路径>。构建的 TEMP/TMP、缓存和产物全部位于项目内。原始应用代码 MIT；Qt/PySide6、Python 等组件沿用各自许可证，见第三方说明。

## 1.0.1 新增训练控制键

快捷键训练页：空格开始／暂停接收按键，答对后 Enter 进入下一题（小键盘 Enter 也支持）。下一题仍需空格开始；未答对时 Enter 不跳题。组合键 Ctrl+Space、Shift+Space 仍是题目作答。长按控制键不会重复触发，控制键不会记录成错题。仅在快捷键训练页生效，公式输入页 Enter 检查公式不变。按钮和页面说明已标注。

## 当前便携版

本版本不要求 D 盘。程序运行库包含在单个 EXE 内，使用系统临时目录解包，数据保存到 EXE 旁的 data。只读目录请先移动到可写位置。原有个人记录需要一并复制 data，发布包不含个人数据。
